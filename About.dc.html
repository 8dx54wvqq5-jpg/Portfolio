◇ 01 · Intro
ABOUT · SENIOR UX DESIGNER

Eight years designing software where a wrong screen costs someone money.

I'm Abhikant Nirbhavane. I design enterprise software for dispute management, card controls, compliance workflows, and quoting. Regulated products, where somebody usually has to explain the decision afterward.

I came to UX from engineering. Computer Engineering first, then a master's in HCI. It means I start with the system instead of the screen. Where does the data break, and can the person using it still tell what happened.

At Fiserv I hold the product owner role as well as the design work on 360 Control, running story refinement with ten engineers. I build with AI too. Claude Code and Copilot turned a concept into a working HTML prototype that SMEs could test, and I designed the Disputes GPT intake pilot so an agent always sees the model's confidence and can overrule it.
